# Coding guidelines

Read before inspecting or changing code, debugging, or reviewing code.

- Read relevant existing code and project instructions before changing behavior. Follow established patterns unless the task calls for a change.
- Write concise, clear code comments that help readers and agents identify what each significant part does. Explain purpose and non-obvious decisions where useful; avoid restating obvious code or adding verbose commentary that bloats agent context. Include enough detail to make the code easy to navigate and understand.
